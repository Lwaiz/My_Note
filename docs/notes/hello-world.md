# 欢迎来到我的 Markdown 博客

这是你的第一个文章。你可以直接把 Markdown 文件放到 `docs/notes` 目录下，并在 `docs/notes/posts.json` 中添加索引。

本站通过 AI 生成源代码，实现基础功能。


## 使用方法

- 写你的笔记到 `docs/notes/你的文件名.md`
- 在 `docs/notes/posts.json` 里新增一个条目：

```json
{
  "slug": "你的文件名",
  "title": "文章标题",
  "description": "文章描述",
  "date": "2026-05-01"
}
```

然后访问 `index.html` 即可看到文章列表。

## 例如

```md
# 这是我的笔记标题

这里是内容。
```
